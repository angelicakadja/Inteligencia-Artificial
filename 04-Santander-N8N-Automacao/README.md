#### 🎓 Sobre o Bootcamp

Este repositório reúne todo o meu aprendizado referente à construção de automações de processos com N8N, conectando Inteligência Artificial, workflows, integrações, APIs e webhooks em uma trilha prática que vai dos fundamentos até um projeto real de RPA com Python.

No projeto final, consolidei tudo isso na construção de um processo de RPA com N8N e Python, combinando automação visual e desenvolvimento técnico em uma entrega prática para o portfólio.
